## 7. 💡 Diagnóstico Forense y Soluciones a Problemas Críticos

| Problema Encontrado | Causa Raíz Diagnosticada | Solución Técnica Definitiva |
| :--- | :--- | :--- |
| **Mixed Content en UI** | El navegador bloqueaba peticiones HTTP a `:8080` desde la app HTTPS. | Creado Reverse Proxy dinámico en Traefik (`/wa-api`) con SSL Let's Encrypt automático. |
| **Error 401 en Supabase** | Clave anónima antigua caducada en el contenedor Python. | Actualizada la variable `SUPABASE_KEY` con la clave `service_role` oficial de `.env`. |
| **Teléfono no reconocido** | En BD estaba `"991 090 016"` (con espacios) vs `"51991090016"` del socket. | Implementado filtro SQL con comodines `%9%9%1%0%9%0%0%1%6%` y normalización de 9 dígitos. |
| **Números en Verde / Negrita (Auto-linking)** | WhatsApp Web detectaba números de 8 dígitos como códigos de área de Perú (`01`, `02`, `04`, etc.). | Implementado el formato estricto `DNI-XXXXXXXX` y generación de falsos en la serie `09` (libre de códigos de área). |
| **Aceptación errónea de PEN** | La versión previa no validaba la moneda contra los contratos reales del cliente. | Vinculado el paso de moneda con `crm_contratos.moneda`, rechazando cualquier opción distinta a `USD`. |

@app.post("/webhook")
async def evolution_webhook(req: Request):
    try:
        body = await req.json()
        event = body.get("event")
        data = body.get("data", {})
        
        if event == "messages.upsert":
            key = data.get("key", {})
            from_me = key.get("fromMe", False)
            remote_jid = key.get("remoteJid", "")
            
            if from_me or "@g.us" in remote_jid:
                return {"status": "ignored"}
                
            message_obj = data.get("message", {})
            conversation = message_obj.get("conversation") or message_obj.get("extendedTextMessage", {}).get("text") or ""
            
            if conversation:
                print(f"Mensaje recibido de {remote_jid}: {conversation}")
                process_bot_flow(remote_jid, conversation)
                
        return {"status": "ok"}
    except Exception as e:
        print(f"Error en webhook: {e}")
        return {"status": "error", "message": str(e)}
