## 1. 🎯 Objetivo del Sistema WhatsApp

Dotar a InAndes ERP de un canal automatizado, bidireccional y blindado de mensajería WhatsApp para dos grandes propósitos:

1. **Notificaciones Transaccionales Post-Transferencia (Unidireccional / Push):**  
   Enviar confirmaciones inmediatas y personalizadas a los teléfonos celulares de los partícipes, proveedores o emisores una vez ejecutado el lote de transferencias bancarias (Telecrédito BCP o transferencias interbancarias).
2. **Agente Financiero Inteligente (Bidireccional / Chatbot Interactivo):**  
   Resucitar y evolucionar el bot financiero de legacy (`15_CRM_Chat.py` / `whatsapp_sim_agent.py`) para que los inversionistas puedan consultar su saldo, rendimiento devengado, último pago y solicitar su Estado de Cuenta PDF en tiempo real con validación segura.

## 4. 🔄 El Circuito Inverso (Recuperación de EECC Históricos en 2 Segundos)

Cuando un partícipe escribe al WhatsApp corporativo solicitando un documento histórico:

1. **Recepción Inmediata (0.1 seg):** Evolution API recibe el mensaje vía WebSocket y dispara un webhook a FastAPI.
2. **Identificación y Seguridad (0.2 seg):** FastAPI consulta `crm_inversionistas` por el número de teléfono y emite el desafío de seguridad (últimos 4 dígitos del DNI o dirección registrada).
3. **Recuperación o Compilación (0.4 seg):**  
   - Si el PDF ya existe en Contabo (`/var/data/documents/...`), lo toma de inmediato.
   - Si no existe, el motor Python (`pdf_generators.py`) compila el Estado de Cuenta con la data histórica de Supabase en 400 milisegundos.
4. **Despacho del PDF (0.5 seg):** Evolution API adjunta el archivo al chat y el cliente lo tiene en sus manos en **menos de 2 segundos**.

## 6. 🌐 ¿Por qué no le pagamos a Mark Zuckerberg? (Mecánica de Evolution API)

* **¿Cómo funciona WhatsApp Web?** Al abrir `web.whatsapp.com` y escanear el QR, el tráfico es gratuito e ilimitado.
* **El Rol de Evolution API / Baileys en Contabo:**  
  Es un emulador en Node.js del protocolo WebSocket de WhatsApp Web.
  1. Se despliega en Docker en Contabo.
  2. Se escanea el código QR con el número celular corporativo de InAndes una sola vez.
  3. Para los servidores de Meta, todos los mensajes enviados por el ERP provienen de una sesión legítima de WhatsApp Web.
  4. **Cero consumo de recursos:** No levanta navegadores gráficos pesados (Chromium); opera a nivel de socket consumiendo apenas **~60 MB de RAM**.

## 8. 🗄️ Modelo de Datos de Auditoría en Supabase (`whatsapp_logs`)

```sql
CREATE TABLE IF NOT EXISTS public.whatsapp_logs (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    destinatario_tipo VARCHAR(30) NOT NULL, -- 'INVERSIONISTA', 'PROVEEDOR', 'EMISOR'
    destinatario_id VARCHAR(50),
    destinatario_nombre VARCHAR(150),
    telefono VARCHAR(25) NOT NULL,
    tipo_mensaje VARCHAR(50) NOT NULL, -- 'NOTIFICACION_ABONO', 'ESTADO_CUENTA', 'CHAT_BOT'
    contenido_mensaje TEXT NOT NULL,
    archivo_adjunto_url TEXT,
    estado VARCHAR(20) DEFAULT 'PENDIENTE', -- 'ENVIADO', 'ENTREGADO', 'LEIDO', 'FALLIDO'
    mensaje_id_externo VARCHAR(100),
    error_detalle TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE INDEX idx_wa_logs_telefono ON public.whatsapp_logs(telefono);
CREATE INDEX idx_wa_logs_estado ON public.whatsapp_logs(estado);
```
