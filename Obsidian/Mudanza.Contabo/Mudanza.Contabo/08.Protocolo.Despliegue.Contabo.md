## 2. Los Dos Métodos Oficiales de Despliegue

Existen dos formas válidas y complementarias de desplegar cambios a producción:

### 🟢 Método A: Despliegue Estándar (Automático por Git Webhook)
*Recomendado para commits generales, merges y safe points oficiales.*

1. **Compilar y validar localmente:**
   ```powershell
   npm run build
   ```
2. **Sincronizar en GitHub (Rama `main`):**
   ```powershell
   git add .
   git commit -m "FEAT/FIX: Descripción clara del cambio"
   git push origin main
   ```
3. **Comportamiento esperado:**
   - GitHub emite el webhook a Coolify.
   - Coolify clona el repositorio y compila el contenedor Docker en background.
   - **Tiempo estimado:** **~2 minutos** (Zero-Downtime: el sitio anterior sigue respondiendo hasta que el nuevo contenedor entra en estado *healthy*).

---

### ⚡ Método B: Despliegue Inmediato Directo (Hot-Deploy en 10 Segundos)
*Recomendado cuando se requiere inmediatez absoluta para auditoría o pruebas en vivo con el usuario sin esperar el ciclo de build de Coolify.*

1. **Compilar localmente:**
   ```powershell
   npm run build
   ```
2. **Ejecutar script de inyección rápida:**
   ```powershell
   python deploy_contabo_fast.py
   ```
3. **¿Qué hace este script?**
   - Se conecta por SSH a `169.58.168.107`.
   - Empaqueta el `dist/` local recién generado.
   - Lo inyecta y extrae directamente en la carpeta `/app/dist` del contenedor activo de producción.
   - **Tiempo estimado:** **10 a 15 segundos** (Refresco inmediato con `Ctrl + F5` en el navegador).

## 3. Script Oficial de Inyección Rápida (`deploy_contabo_fast.py`)

Ubicado en la raíz del proyecto:

```python
import io
import os
import tarfile
import paramiko

CONTABO_IP = '169.58.168.107'
CONTABO_PORT = 22
CONTABO_USER = 'root'
CONTABO_PASS = 'VivaLaVida2026$'
APP_PREFIX = 'yjttbctaekty8zb5ode0hiu4'

def deploy_fast():
    print(f"[*] Conectando a VPS Contabo ({CONTABO_IP})...")
    ssh = paramiko.SSHClient()
    ssh.set_missing_host_key_policy(paramiko.AutoAddPolicy())
    ssh.connect(CONTABO_IP, port=CONTABO_PORT, username=CONTABO_USER, password=CONTABO_PASS)
    
    # 1. Obtener el contenedor activo
    stdin, stdout, stderr = ssh.exec_command(f'docker ps --filter "name={APP_PREFIX}" --format "{{{{.Names}}}}"')
    containers = stdout.read().decode().strip().splitlines()
    if not containers:
        print("[!] Error: No se encontró un contenedor activo para el frontend.")
        ssh.close()
        return
    
    container_name = containers[0]
    print(f"[*] Contenedor activo detectado: {container_name}")
    
    # 2. Empaquetar dist local
    dist_dir = os.path.abspath("dist")
    print(f"[*] Empaquetando {dist_dir}...")
    tar_stream = io.BytesIO()
    with tarfile.open(fileobj=tar_stream, mode='w') as tar:
        for root, dirs, files in os.walk(dist_dir):
            for file in files:
                full_path = os.path.join(root, file)
                rel_path = os.path.relpath(full_path, dist_dir)
                tar.add(full_path, arcname=rel_path)
    tar_bytes = tar_stream.getvalue()
    
    # 3. Transferir vía SFTP
    sftp = ssh.open_sftp()
    with sftp.file('/tmp/dist.tar', 'wb') as f:
        f.write(tar_bytes)
    sftp.close()
    print("[*] Archivo transferido a /tmp/dist.tar")
    
    # 4. Inyectar en el contenedor
    cmd = f'docker cp /tmp/dist.tar {container_name}:/app/dist.tar && docker exec {container_name} tar -xf /app/dist.tar -C /app/'
    stdin, stdout, stderr = ssh.exec_command(cmd)
    stdout.channel.recv_exit_status()
    
    ssh.close()
    print("[✓] DESPLIEGUE EXITOSO: Aplicación actualizada en https://inandes.geeksoft.tech")

if __name__ == '__main__':
    deploy_fast()
```
