# 21. Herramientas de Auditoria Forense y Device Vault (Libro Mayor Inmutable y Zero-Trust)

## 1. Resumen Ejecutivo y Proposito
Con el objetivo de eliminar cualquier tipo de discrepancia operacional ("quien hizo que", modificaciones de certificados, rescates o aumentos no registrados) y garantizar el control estricto de accesos por hardware, se clonaron e integraron 1:1 las dos herramientas forenses de **PETRAL SMART DASHBOARD** al ecosistema **InAndes ERP React**:

1. **Bitacora de Auditoria Forense (Audit Ledger Master)**: Registro transaccional inmutable que almacena la traza de eventos, diferencias JSON (`old_data`, `new_data`, `diff_data`), usuario ejecutor, IP y User-Agent.
2. **Boveda de Dispositivos (Device Vault)**: Control de inventario y estado Zero-Trust de hardware fisico (`AUTHORIZED`, `PENDING_APPROVAL`, `REVOKED`) mediante huella digital criptografica de hardware (Fingerprint).

Ambos modulos se encuentran disponibles en el menu lateral dentro de la seccion **Herramientas**.

## 2. Arquitectura de Datos (Supabase Cloud)

Se crearon y aseguraron con Row Level Security (RLS) dos tablas centrales en PostgreSQL:

### A. Tabla `public.audit_logs`
```sql
CREATE TABLE IF NOT EXISTS public.audit_logs (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    table_name VARCHAR(100) NOT NULL,
    record_id VARCHAR(100),
    action VARCHAR(50) NOT NULL, -- INSERT, UPDATE, DELETE, VIEW, EXPORT_EXCEL, EXPORT_PDF, LOGIN, SYSTEM
    user_email VARCHAR(255) NOT NULL,
    ip_address VARCHAR(50),
    user_agent TEXT,
    old_data JSONB,
    new_data JSONB,
    diff_data JSONB,
    metadata JSONB,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX IF NOT EXISTS idx_audit_logs_created_at ON public.audit_logs(created_at DESC);
CREATE INDEX IF NOT EXISTS idx_audit_logs_user_email ON public.audit_logs(user_email);
CREATE INDEX IF NOT EXISTS idx_audit_logs_table_name ON public.audit_logs(table_name);
```

### B. Tabla `public.user_authorized_devices`
```sql
CREATE TABLE IF NOT EXISTS public.user_authorized_devices (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_email VARCHAR(255) NOT NULL,
    device_fingerprint VARCHAR(255) NOT NULL,
    device_name VARCHAR(255) NOT NULL,
    ip_address VARCHAR(50),
    status VARCHAR(50) DEFAULT 'PENDING_APPROVAL', -- AUTHORIZED, PENDING_APPROVAL, REVOKED
    approved_by VARCHAR(255),
    approved_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    last_access_at TIMESTAMPTZ DEFAULT NOW(),
    CONSTRAINT uq_user_device UNIQUE (user_email, device_fingerprint)
);

CREATE INDEX IF NOT EXISTS idx_user_devices_status ON public.user_authorized_devices(status);
CREATE INDEX IF NOT EXISTS idx_user_devices_user ON public.user_authorized_devices(user_email);
```

## 3. Modulos y Componentes Implementados en Frontend

### A. `src/services/auditService.ts`
Capa de servicio que interactua directamente con Supabase para:
- `getAuditLogs()`: Recuperacion paginada y ordenada de eventos de auditoria con soporte para filtros por usuario, tabla y accion.
- `logEvent()`: Registro directo de eventos transaccionales con calculo automatico de diferencias JSON.
- `getDevices()`: Listado de dispositivos con sus estados de autorizacion.
- `approveDevice(id, approver)`: Autorizacion inmediata de terminal de trabajo.
- `revokeDevice(id)`: Revocacion y bloqueo de acceso para el hardware especificado.

### B. `src/services/auditTracker.ts`
Modulo de telemetria no invasivo y asincrono (fire-and-forget):
- Genera huella digital del dispositivo local basada en pantalla, nucleos CPU, canvas y memoria (`FP-XXXXXXXX`).
- Extrae metadatos de navegacion y resuelve IP publica de manera transparente.
- Expone metodos de captura automatica `trackAudit()`, `trackAuth()` y `trackExport()`.

### C. `src/features/herramientas/AuditMasterPage.tsx`
Pantalla pericial interactiva:
- **Barra de Usuarios con Avatar**: Selector visual rapido con contadores de actividad por usuario.
- **Filtros Avanzados**: Por tipo de accion (`ALL`, `INSERT`, `UPDATE`, `DELETE`, `EXPORT_EXCEL`, `EXPORT_PDF`), modulo/tabla y busqueda de texto libre.
- **Visualizador de Deltas**: Muestra clara de valores anteriores vs valores nuevos destacados con color.
- **Modal de Ficha Forense**: Visor JSON completo con opcion de copia en un clic.
- **Exportacion a Excel**: Descarga instantanea del libro mayor de auditoria para inspecciones formales.

### D. `src/features/herramientas/DeviceVaultPage.tsx`
Boveda de control de hardware:
- **Tarjetas de Metricas**: Total Dispositivos, Autorizados, Pendientes y Revocados.
- **Grid de Dispositivos**: Muestra correo de usuario, nombre de equipo (OS/Navegador), huella criptografica, IP y ultima fecha de acceso.
- **Acciones Directas**: Botones de "Aprobar Acceso" y "Revocar Acceso" con actualizacion en tiempo real.

## 5. Instrumentacion Transaccional Activa
Se configuro tracking automatico en operaciones criticas del ERP:
1. **Certificados de Inversionistas**: Creacion de Aumentos de Capital (`certificadosService.insertAumentoCapital`) registra automaticamente la tabla `inversionista_eventos_historico` con el JSON completo.
2. **Exportacion Excel / PDF**: Toda generacion o descarga de reportes registra el usuario que extrajo los datos, la cantidad de filas y la marca de tiempo.
