## 6. Script Oficial de Control de Calidad Forense 360 (`audit_deep_orphans_and_ledger.py`)

Para garantizar que ningún agente ni proceso futuro altere la consistencia sin ser detectado, se deja como estándar el siguiente script de verificación:

```python
from collections import Counter
from supabase import create_client

url = "https://egvcinsbyropumybatdf.supabase.co"
key = "..." # Credencial Supabase del proyecto
sb = create_client(url, key)

# 1. Cargar tablas maestras
invs = sb.table('crm_inversionistas').select('*').execute().data or []
fondos = sb.table('crm_fondos').select('*').execute().data or []
contratos = sb.table('crm_contratos').select('*').execute().data or []
eventos = sb.table('crm_certificados_eventos').select('*').order('id_evento').execute().data or []
cuotas = sb.table('crm_cronograma_deducciones_rescates').select('*').execute().data or []

inv_map = {str(i.get('codigo_inversionista') or i.get('documento_identidad')).strip(): i for i in invs}
fondo_map = {f['id_fondo']: f for f in fondos}
contrato_map = {c['id_contrato']: c for c in contratos}
evento_map = {e['id_evento']: e for e in eventos}

# 2. Validar Paternidad de Contratos
contratos_sin_padre = [c for c in contratos if not inv_map.get(c.get('id_inversionista_1')) or not fondo_map.get(c.get('id_fondo'))]
print(f"Contratos sin Padre Valido: {len(contratos_sin_padre)}")

# 3. Validar Paternidad de Eventos Ledger
eventos_sin_padre = [e for e in eventos if not contrato_map.get(e.get('id_contrato'))]
print(f"Eventos Ledger sin Contrato Padre: {len(eventos_sin_padre)}")

# 4. Validar Paternidad de Cuotas
cuotas_sin_padre = [q for q in cuotas if not contrato_map.get(q.get('id_contrato') or q.get('id_certificado'))]
print(f"Cuotas sin Contrato Padre: {len(cuotas_sin_padre)}")
```
