# 03. Migración de Base de Datos Supabase a Postgres-Coolify

> **GUÍA DE MIGRACIÓN DE BD:** Estrategia para mover el esquema y datos de Supabase Cloud (`egvcinsbyropumybatdf`) hacia la base de datos auto-hospedada en Contabo.

---

## 🏗️ 2 Opciones de Despliegue de BD en Coolify

Existen dos estrategias para alojar la base de datos en Contabo:

### Opción A: Supabase Self-Hosted (1-Click en Coolify) — **RECOMENDADA**
- **Pros:** Mantienes Supabase Studio, GoTrue (Autenticación JWT, Google OAuth), PostgREST, Realtime y Storage API exactamente igual a como funcionan en Supabase Cloud.
- **Cómo hacerlo:** En Coolify ➔ *Add Resource* ➔ *Service* ➔ Seleccionar **Supabase** ➔ Hacer clic en **Install**.
- **Encendido de Recursos:** Al crearse la pila, los 15 microservicios figurarán en estado `Exited` (rojo). Haz clic en el botón morado de la esquina superior derecha **`Actions` ➔ `Start`** para pasarlos a estado `Running` (verde).

### Opción B: PostgreSQL Standalone + PgBouncer
- **Pros:** Consume menos memoria RAM (~300MB vs ~1.5GB de la suite Supabase).
- **Cons:** El frontend React debe consultar todo vía el backend FastAPI o conectores directos, omitiendo llamadas directas con el SDK `@supabase/supabase-js`.

---

## 📦 Paso 1: Dump Completo de la Base de Datos desde Supabase Cloud

Ejecuta este comando desde tu equipo local o servidor de administración para extraer la base de datos de producción:

```bash
# Exportar esquema y datos completos de Supabase Cloud
pg_dump "postgresql://postgres.egvcinsbyropumybatdf:[TU_PASSWORD_SUPABASE]@aws-0-us-west-1.pooler.supabase.com:6543/postgres?sslmode=require" \
  --clean \
  --if-exists \
  --quote-all-identifiers \
  --no-owner \
  --no-privileges \
  --file=supabase_dump_inandes.sql
```

---

## 📥 Paso 2: Importar la Base de Datos en el Postgres de Contabo

Una vez que el servicio de Postgres / Supabase esté activo en Coolify:

1. Transfiere el archivo `supabase_dump_inandes.sql` al VPS de Contabo:
   ```bash
   scp supabase_dump_inandes.sql root@TU_IP_CONTABO:/tmp/
   ```

2. Restaura la base de datos en el contenedor de Postgres de Coolify:
   ```bash
   # Obtener el ID o Nombre del contenedor de PostgreSQL en Coolify
   docker ps | grep postgres

   # Copiar dump al contenedor de Postgres
   docker cp /tmp/supabase_dump_inandes.sql [CONTAINER_ID]:/tmp/dump.sql

   # Ejecutar restauración
   docker exec -it [CONTAINER_ID] psql -U postgres -d postgres -f /tmp/dump.sql
   ```

## 🔐 Paso 3: Sincronización de Extensiones y Llaves JWT

Asegúrate de que las siguientes extensiones requeridas por tu ERP estén activadas en el Postgres de Contabo:

```sql
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
CREATE EXTENSION IF NOT EXISTS "pgcrypto";
CREATE EXTENSION IF NOT EXISTS "pg_trgm";
```

### Configuración de Claves Supabase en Coolify (.env):
En el recurso de Supabase/Postgres dentro de Coolify, configura:
- `JWT_SECRET`: Debe ser una cadena de 32+ caracteres segura.
- `ANON_KEY` y `SERVICE_ROLE_KEY`: Generadas con la misma firmas JWT.
- `POSTGRES_PASSWORD`: Contraseña fuerte para la conexión de FastAPI.

## 🧪 Paso 4: Verificación de Tablas Críticas

Conéctate a la BD de Contabo e inspecciona que todas las tablas y esquemas existan:

```sql
-- Verificar conteo de tablas en esquema public
SELECT count(*) FROM information_schema.tables WHERE table_schema = 'public';

-- Verificar registros clave
SELECT count(*) FROM propuestas;
SELECT count(*) FROM inversionistas;
SELECT count(*) FROM contratos_inversion;
```
