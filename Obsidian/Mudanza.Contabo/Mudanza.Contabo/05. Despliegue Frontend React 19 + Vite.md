# 05. Despliegue Frontend React 19 + Vite

> **DESPLIEGUE DEL FRONTEND:** Configuración de la aplicación React 19 en Coolify con Proxy Reverso Traefik, HTTPS y Auto-Deploy vía Git Push.

---

## ⚛️ Contexto del Frontend React

- **Tecnología:** React 19, Vite, TypeScript, Tailwind CSS.
- **Repositorio:** `RichGutz/Inandes.ERP.React` (`origin/main`).
- **Comando de Compilación:** `npm run build` (genera `/dist`).

---

## 📄 Opción 1: Despliegue mediante Nixpacks / Static (Coolify Nativo)

Coolify detecta proyectos Vite automáticamente. Solo debes configurar en el panel:

1. **Build Pack:** `Nixpacks` (o Static Site).
2. **Install Command:** `npm install`
3. **Build Command:** `npm run build`
4. **Publish Directory:** `dist`
5. **Port Exposed:** `80` (Coolify levantará un servidor Nginx interno para la SPA).

---

## 📄 Opción 2: Dockerfile Personalizado para Nginx (RECOMENDADO para SPAs)

Para garantizar que el enrutamiento de React (`react-router-dom`) no devuelva error 404 al recargar la página en subrutas (`/inversionistas`, `/aprobaciones`), se incluye una regla `try_files` de Nginx:

### 1. `nginx.conf`:
```nginx
server {
    listen 80;
    server_name localhost;

    location / {
        root /usr/share/nginx/html;
        index index.html index.htm;
        try_files $uri $uri/ /index.html;
    }

    error_page 500 502 503 504 /50x.html;
    location = /50x.html {
        root /usr/share/nginx/html;
    }
}
```

### 2. `Dockerfile.frontend`:
```dockerfile
# Etapa 1: Build de React
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
# Pasar variables VITE_ en tiempo de compilacion
ARG VITE_SUPABASE_URL
ARG VITE_SUPABASE_ANON_KEY
ARG VITE_API_FACTORING_URL
ENV VITE_SUPABASE_URL=$VITE_SUPABASE_URL
ENV VITE_SUPABASE_ANON_KEY=$VITE_SUPABASE_ANON_KEY
ENV VITE_API_FACTORING_URL=$VITE_API_FACTORING_URL
RUN npm run build

# Etapa 2: Servidor Nginx
FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

## 🔐 Configuración de Variables de Entorno en Coolify

En Coolify ➔ *Resource Config* ➔ *Environment Variables*:

```ini
VITE_SUPABASE_URL=https://[TU_DOMINIO_CONTABO_POSTGRES_O_SUPABASE]
VITE_SUPABASE_ANON_KEY=ey...
VITE_API_FACTORING_URL=https://api-factoring.geeksoft.tech
```

> **IMPORTANTE:** Marcar la casilla **"Is Build Variable?"** en Coolify para que Vite pueda incrustar estas variables durante `npm run build`.

## 🔄 Verificación del Auto-Deploy por Git

Gracias a la GitHub App vinculada en el Paso 2 del plan maestro:
- Cada ejecucion de:
  ```powershell
  git add .
  git commit -m "feat: actualización de interfaz"
  git push origin main
  ```
- Disparará un Webhook directo a Coolify.
- Coolify compilará la nueva versión en segundo plano y sustituirá el contenedor en caliente sin interrumpir a los usuarios activos (Zero-Downtime Deployment).
