# 02. Infraestructura y Hardening del Server Contabo

> **GUÍA DE PREPARACIÓN DE VPS:** Configuración inicial del servidor Linux en Contabo para soportar Coolify, Docker, Postgres y FastAPI sin colapsar.

---

## 🖥️ Especificaciones Recomendadas del VPS (Contabo)

Para operar la base de datos Supabase/Postgres, Coolify, Traefik, FastAPI y el Frontend React holgadamente, se recomienda mínimamente:
- **Plan Contabo:** Cloud VPS M o L
- **vCPU:** 4 u 8 Cores
- **RAM:** 8 GB o 16 GB RAM
- **Disco:** 200 GB NVMe
- **Sistema Operativo:** Ubuntu 22.04 LTS (o 24.04 LTS) 64-bit

## 💾 Paso 2: Creación Obligatoria de Memoria SWAP (8 GB)

**IMPORTANTE:** Este paso previene que Docker o Coolify se congelen durante la compilación de paquetes frontend o arranques pesados de Postgres.

```bash
# 1. Crear archivo swap de 8GB
fallocate -l 8G /swapfile

# 2. Asignar permisos estrictos
chmod 600 /swapfile

# 3. Formatear como área de intercambio
mkswap /swapfile

# 4. Activar el Swap
swapon /swapfile

# 5. Hacerlo permanente al reiniciar el VPS
echo '/swapfile none swap sw 0 0' >> /etc/fstab

# 6. Ajustar Swappiness (optimización para base de datos y containers)
sysctl vm.swappiness=20
echo 'vm.swappiness=20' >> /etc/sysctl.conf

# 7. Verificar activación
free -h
```

---

## 🛡️ Paso 3: Configuración del Firewall (UFW)

Es fundamental abrir únicamente los puertos estrictamente necesarios:

```bash
# Permitir SSH (Puerto 22)
ufw allow 22/tcp

# Permitir HTTP (Puerto 80) y HTTPS (Puerto 443) para Nginx / Traefik
ufw allow 80/tcp
ufw allow 443/tcp

# Permitir Puerto 8000 para el Dashboard Web de Coolify
ufw allow 8000/tcp

# Activar el Firewall
ufw enable
```

---

## 🚀 Paso 4: Instalación Oficial de Coolify v4

Una vez asegurado el VPS y creado el SWAP, ejecuta el instalador oficial de Coolify:

```bash
curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash
```

### ¿Qué hace este script automáticamente?
1. Instala Docker Engine y Docker Compose plugin.
2. Instala el motor de Coolify y su Proxy Reverso (**Traefik**).
3. Habilita los volúmenes de almacenamiento en `/data/coolify`.
