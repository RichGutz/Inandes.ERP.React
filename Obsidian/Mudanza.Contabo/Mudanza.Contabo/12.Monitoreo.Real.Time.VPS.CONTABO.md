## 2. 🔑 Configuración de Streaming

### A. Servidor Padre (Contabo - `169.58.168.107`)
- **Archivo:** `/etc/netdata/stream.conf`
```ini
[c4b96791-7643-4c92-a1f7-e431f13a1a9e]
    enabled = yes
    default history = 3600
    default memory mode = dbengine
    health enabled by default = auto
    allow from = *
```

- **Enrutamiento Traefik Dinámico:** `/data/coolify/proxy/dynamic/netdata.yaml`
```yaml
http:
  routers:
    netdata-http:
      rule: "Host(`netdata.geeksoft.tech`)"
      entryPoints:
        - http
      middlewares:
        - redirect-to-https
      service: netdata-service
    netdata-https:
      rule: "Host(`netdata.geeksoft.tech`)"
      entryPoints:
        - https
      tls:
        certResolver: letsencrypt
      service: netdata-service

  services:
    netdata-service:
      loadBalancer:
        servers:
          - url: "http://host.docker.internal:19999"
```

---

### B. Servidor Hijo (Hostinger - `91.108.125.253`)
- **Archivo:** `/etc/netdata/stream.conf`
```ini
[stream]
    enabled = yes
    destination = 169.58.168.107:19999
    api key = c4b96791-7643-4c92-a1f7-e431f13a1a9e
```

- **Modo Ultra-Ligero (Headless):** `/etc/netdata/netdata.conf`
```ini
[web]
    mode = none

[db]
    mode = none
```
*(No consume memoria en base de datos local ni levanta servidor web en Hostinger; transmite todo en crudo a Contabo).*
