# 24. Protocolo de Conmutación a Dominio Temporal (`bolt-usa.shop`) y Procedimiento de Reversión

---

## 📌 1. Resumen Ejecutivo y Causa de la Conmutación

Debido a una suspensión administrativa temporal por parte de Google Cloud Platform hacia el proyecto `InandesFactoringApp` (ID: `intense-plate-470703-v8`), el registrador/proveedor de `geeksoft.tech` bloqueó temporalmente el dominio raíz y sus subdominios.

Para garantizar la **continuidad operativa 100% inmediata del ERP de Factoring e Inversionistas de INANDES**, se ejecuta una **conmutación controlada hacia el dominio temporal de contingencia `bolt-usa.shop`**, manteniendo exactamente la misma infraestructura subyacente en el **VPS Contabo (`169.58.168.107`)** y **Supabase (`egvcinsbyropumybatdf`)**.

---

## 🏗️ 2. Arquitectura de Conmutación Temporal

```
[ Usuario Final ]
        │
        ▼
[ DNS: bolt-usa.shop ]
  ├── inandes.bolt-usa.shop       ──(Registro A)──> 169.58.168.107 (VPS Contabo)
  └── api-factoring.bolt-usa.shop ──(Registro A)──> 169.58.168.107 (VPS Contabo)
        │

[ VPS Contabo (169.58.168.107) - Coolify / Traefik / Caddy ]
  ├── Frontend React 19 (SPA): https://inandes.bolt-usa.shop (Auto-SSL Let's Encrypt)
  └── Backend FastAPI (8010):  https://api-factoring.bolt-usa.shop (Auto-SSL Let's Encrypt)
        │
        ▼
[ Supabase Cloud (egvcinsbyropumybatdf) ]
  ├── Site URL: https://inandes.bolt-usa.shop
  └── Redirect Allow List: https://inandes.bolt-usa.shop/**
```

## 🛠️ 3. Pasos de Conmutación Ejecutados (Hacia `bolt-usa.shop`)

### Paso 1: Configuración DNS (Completada ✅)
Se crearon en el panel DNS de `bolt-usa.shop` los siguientes registros:

| Tipo | Host | Destino | TTL | Estado |
| :--- | :--- | :--- | :--- | :--- |
| **A** | `inandes` | `169.58.168.107` | 3600 / Auto | ✅ Resuelto en terminal |
| **A** | `api-factoring` | `169.58.168.107` | 3600 / Auto | ✅ Resuelto en terminal |

### Paso 2: Reconfiguración en Coolify (VPS Contabo `169.58.168.107:8000`)
1. **Recurso Frontend (React 19)**:
   - **Domains (FQDN)**: Cambiar `https://inandes.geeksoft.tech` ➔ `https://inandes.bolt-usa.shop`
   - Acción: Click en **Save** ➔ **Redeploy**.
   - Traefik emite automáticamente el certificado SSL Let's Encrypt para `inandes.bolt-usa.shop`.
2. **Recurso Backend (FastAPI)**:
   - **Domains (FQDN)**: Cambiar `https://api-factoring.geeksoft.tech` ➔ `https://api-factoring.bolt-usa.shop`
   - Acción: Click en **Save** ➔ **Redeploy**.

### Paso 3: Supabase Cloud (`egvcinsbyropumybatdf`)
1. Ingresar a **Authentication** ➔ **URL Configuration**:
   - **Site URL**: `https://inandes.bolt-usa.shop`
   - **Redirect URLs (Allow List)**:
     - `https://inandes.bolt-usa.shop/**`
     - `https://inandes.bolt-usa.shop`
2. Guardar cambios.

### Paso 4: Limpieza de URLs en Código Fuente (Frontend React)
- Se sustituyen fallbacks absolutos por `getApiBaseUrl()` de `src/config/apiConfig.ts`, garantizando que todas las llamadas de la API usen rutas relativas delegadas al proxy del dominio activo.

## 🔄 4. Procedimiento de Reversión (Vuelta a `geeksoft.tech`)

Una vez resuelta la apelación ante Google Cloud y rehabilitado el dominio `geeksoft.tech`, se debe seguir este procedimiento inverso exacto:

### Fase R1: Verificación de DNS de `geeksoft.tech`
Antes de tocar los servidores, validar en terminal que los registros apunten al VPS Contabo:
```powershell
Resolve-DnsName inandes.geeksoft.tech
Resolve-DnsName api-factoring.geeksoft.tech
# Ambos deben responder: 169.58.168.107
```

### Fase R2: Reconfiguración en Coolify (`169.58.168.107:8000`)
1. **Frontend (React)**:
   - Modificar FQDN de `https://inandes.bolt-usa.shop` ➔ **`https://inandes.geeksoft.tech`**
   - Click en **Save** y **Redeploy**.
2. **Backend (FastAPI)**:
   - Modificar FQDN de `https://api-factoring.bolt-usa.shop` ➔ **`https://api-factoring.geeksoft.tech`**
   - Click en **Save** y **Redeploy**.

### Fase R3: Reversión en Supabase Cloud
1. En **Authentication** ➔ **URL Configuration**:
   - **Site URL**: `https://inandes.geeksoft.tech`
   - **Redirect URLs**:
     - `https://inandes.geeksoft.tech/**`
     - `https://inandes.geeksoft.tech`
2. Guardar cambios.

### Fase R4: Google Cloud OAuth (Si aplica)
1. En **Google Cloud Console ➔ APIs & Services ➔ Credentials ➔ OAuth 2.0 Client ID**:
   - **Authorized JavaScript origins**: `https://inandes.geeksoft.tech`
   - **Authorized redirect URIs**: `https://egvcinsbyropumybatdf.supabase.co/auth/v1/callback`
