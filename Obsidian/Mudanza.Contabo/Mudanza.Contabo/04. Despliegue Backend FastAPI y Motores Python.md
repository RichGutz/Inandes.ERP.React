# 04. Despliegue Backend FastAPI y Motores Python

> **DOCKERIZACIÓN Y DESPLIEGUE DEL BACKEND:** Cómo empaquetar FastAPI y los motores financieros Python en Coolify con soporte de librerías del sistema.

---

## 🐍 Contexto del Backend FastAPI (`inandes-api`)

El backend Python aloja los motores financieros indispensables del ERP:
- **Motor de Retornos V32/V40** (Devengos, impuestos de 2da categoría)
- **Motor de Valor Cuota V25** (Patrimonio diario de fondos)
- **Motor de Comisiones V2** (Liquidación de asesores)
- **Generador & Parser de PDFs** (PyPDF2, pdf2image, reportlab)

---

## 📄 Paso 1: Crear Dockerfile en el Repositorio de Backend

Para garantizar que Coolify instale las librerías de Python y dependencias de sistema requeridas (como Poppler/Ghostscript), se requiere un `Dockerfile` optimizado:

```dockerfile
# Dockerfile para FastAPI en Coolify
FROM python:3.11-slim

# Evitar escritura de bytecode de python y forzar stdout sin buffer
ENV PYTHONDONTWRITEBYTECODE 1
ENV PYTHONUNBUFFERED 1

# Instalación de librerías del sistema operativo
RUN apt-get update && apt-get install -y \
    build-essential \
    libpq-dev \
    poppler-utils \
    ghostscript \
    tesseract-ocr \
    curl \
    && rm -rf /var/lib/apt/lists/*

WORKDIR /app

# Copiar requerimientos e instalar dependencias Python
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Copiar código fuente
COPY . .

# Puerto expuesto para FastAPI
EXPOSE 8010

# Comando de ejecución con Uvicorn
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8010", "--workers", "4"]
```

## ⚙️ Paso 2: Creación del Recurso en Coolify

1. Entra a tu proyecto en el Dashboard de Coolify.
2. Haz clic en **+ Add Resource** ➔ **Private Repository (with GitHub App)**.
3. Selecciona el repositorio de GitHub (`RichGutz/Inandes.ERP.React` o el repo de backend).
4. **Build Pack:** Selecciona `Dockerfile`.
5. **Port Exposed:** `8010`.
6. **FQDN / Dominio:** `https://api-factoring.geeksoft.tech` (o dominio de staging `https://api-staging.geeksoft.tech`).
