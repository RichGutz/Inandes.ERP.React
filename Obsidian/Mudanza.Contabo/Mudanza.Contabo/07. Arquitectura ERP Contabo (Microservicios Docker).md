# 07. Arquitectura ERP Contabo (Microservicios Docker)

> **DISEÑO DE ARQUITECTURA Y INFRAESTRUCTURA DEDICADA:** Explicación de la topología de contenedores independientes, proxy reverso Traefik y comunicación entre microservicios en el VPS Contabo.

---

## 🏗️ Topología General de Infraestructura

A diferencia de un sistema monolítico tradicional, el ecosistema ERP InAndes en Contabo opera bajo una **Arquitectura de Microservicios Contenerizada (Docker)** administrada mediante **Coolify v4**.

```
                           🌐 INTERNET (Usuarios / SSL)
                                       │
                                       ▼
                       🛡️ TRAEFIK EDGE PROXY (Port 80/443)
                                       │
      ┌────────────────────────────────┼────────────────────────────────┐
      │                                │                                │
      ▼                                ▼                                ▼
📦 Contenedor 1               📦 Contenedor 2                 📦 Contenedor 3
Frontend React 19             Backend FastAPI                 PostgreSQL / Supabase
(Nginx Servidor SPA)          (Motores Python V32/V25)        (Base de Datos & Auth)
Port 80 (Internal)            Port 8010 (Internal)            Port 5432 (Internal)
```

---

## 🧩 Componentes del Ecosistema en Contabo

| Componente | Tipo de Recurso | Función Principal |
|---|---|---|
| **Traefik** | Edge Proxy / Reverse Proxy | Recibe el tráfico HTTP/HTTPS, enruta subdominios y gestiona certificados SSL de Let's Encrypt automáticamente. |
| **Frontend React 19** | Contenedor Nginx (SPA) | Interfaz gráfica consumida por los usuarios (`inandes.react.geeksoft.tech`). Servidor de assets estáticos y React Router. |
| **Backend FastAPI** | Contenedor Python 3.11 | API REST de servicios financieros, motor de retornos V32, devengos de cuota V25, comisiones V2 y generador/parser de PDFs. |
| **Supabase Self-Hosted** | Suite de Contenedores | Pila completa de base de datos PostgreSQL, GoTrue (Auth), PostgREST (API de datos JS) y Supabase Studio (UI de BD). |

---

## ⚡ Ventajas Técnicas Innegociables

### 1. Aislamiento Total por Contenedor
Si el backend FastAPI se reinicia por una actualización de código Python o un cambio en los router, **la base de datos PostgreSQL y el Frontend React permanecen 100% operativos** sin sufrir micro-cortes.

### 2. Latencia Cero (< 1 ms)
Al convivir los contenedores dentro del mismo bus de red privada de Docker (`bridge network`) en el VPS Contabo:
- Las consultas SQL de FastAPI a PostgreSQL responden en **< 1 milisegundo** (frente a los ~100ms de latencia que existían al viajar por internet hacia EE.UU. en Supabase Cloud).

### 3. Escalabilidad Horizontal Futura a 1 Clic
Si en el futuro la base de datos o el volumen de transacciones crece y se requiere mover la BD a un servidor dedicado exclusivo:
- Coolify permite desacoplar el contenedor de PostgreSQL a otro VPS por IP privada **sin reescribir una sola línea de código**.

### 4. Eficiencia Financiera y Control Absoluto
Se eliminan las facturas por límites de almacenamiento de Supabase Cloud o hosting externo, consolidando todo en la infraestructura dedicada de Contabo.
