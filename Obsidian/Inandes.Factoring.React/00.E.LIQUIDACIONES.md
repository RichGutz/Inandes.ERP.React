## 🔄 Endpoints FastAPI (`backend/routers/liquidaciones.py`)

- **`GET /api/liquidaciones/pendientes`**: Retorna el listado clasificado de facturas desde Supabase (`egvcinsbyropumybatdf`) en `nuevas` (`DESEMBOLSADA`) y `en_proceso` (`EN PROCESO DE LIQUIDACION`).
- **`POST /api/liquidaciones/simular`**: Ejecuta el motor oráculo (`generar_tabla_maestra_auditoria`) y evalúa el candado financiero (cobertura mínima de costos acumulados).
- **`GET /api/liquidaciones/{proposal_id}/pdf`**: Genera en tiempo real el PDF ejecutivo usando WeasyPrint y re-importación dinámica (`importlib.reload`).
- **`POST /api/liquidaciones/procesar`**: Registra la cobranza masiva o individual, actualiza el estado a `LIQUIDADA` o `EN PROCESO DE LIQUIDACION` en Supabase y sube las evidencias a Google Drive.

## 🛠️ Lecciones Aprendidas y Soluciones Definitivas en Backend

1. **Resolución de URL en Producción (`LiquidacionReporteModal.tsx`):**
   - **Problema:** En producción, `getApiBaseUrl()` retorna `""` para el proxy Nginx. Al ejecutar `new URL(path)` con 1 argumento, lanzaba `TypeError: Invalid URL`.
   - **Solución:** Se forzó el origen base explícito: `new URL(path, window.location.origin)` y el escape seguro `encodeURIComponent(proposalId)`.

2. **Solución a Error `TypeError: the JSON object must be str, bytes or bytearray, not NoneType`:**
   - **Problema:** En `routers/liquidaciones.py`, al consultar `detalles.get('recalculate_result_json', '{}')`, cuando el valor en la base de datos era `None`, el fallback no actuaba y `json.loads(None)` fallaba con Error 500.
   - **Solución Definitiva:** Se implementó `safe_parse_json()` que valida si el dato es `None`, `dict` o `str`, asegurando que la tabla de auditoría diaria y el PDF de liquidación se generen siempre con 100% de éxito.

3. **Incrustación de Logos Oficiales Base64:**
   - Se inyectaron `LOGO_GEEKSOFT_B64` y `LOGO_INANDES_B64` directamente en el código de `generar_pdfs_liquidacion.py` para WeasyPrint.

## 🔌 Estrategia de Conexión FastAPI & Resiliencia con Supabase

- **Consumo Exclusivo por Capa de Servicio:** Todos los módulos operacionales (`DesembolsosTab`, `LiquidacionesTab`, `AprobacionesTab`, `DashboardTab`) utilizan `factoringService.ts`. Se prohíben las llamadas `fetch('/api/...')` directas en componentes UI.
- **Fallback Automático Hacia Supabase:** Si el backend FastAPI en `https://api-factoring.geeksoft.tech` (puerto `8010`) está reiniciándose o no responde, la capa de servicio conmuta inmediatamente sin error visual y obtiene los registros directamente de Supabase (`propuestas`).
- **Incrustación de Variables en Bundle de Producción:** Las credenciales de Supabase y FastAPI están definidas en `.env`, `.env.local` y `.env.production` para ser empaquetadas permanentemente por Vite al ejecutar `npm run build`.
