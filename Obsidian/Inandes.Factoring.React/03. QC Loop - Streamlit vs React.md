## Analisis de la Diferencia

La diferencia en interes (S/ 3.73) se debe a precision de punto flotante:
- tasa_diaria = 0.025 / 30 = 0.000833...
- formula: interes = capital * (((1 + tasa_diaria) ^ plazo) - 1)

Diferencia = 3.73 / 12255.42 = **0.030% del capital**. Marginal e inofensivo.

**Causa probable:** Version de Python diferente (Windows Python 3.12 vs Linux en VPS). El algoritmo es IDENTICO.
