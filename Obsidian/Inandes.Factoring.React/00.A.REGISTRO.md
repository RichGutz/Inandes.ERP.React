# 01.A. Módulo de Registro (Gestión de Emisores y Aceptantes) - Análisis Funcional, Campos y UI

## 📌 1. Visión General del Módulo

El módulo de **Registro de Involucrados** (Emisores y Aceptantes) es el maestro de entidades corporativas de **INANDES ERP**. En este módulo se registran, consultan y editan los clientes (Cedentes / Emisores) y sus pagadores (Adquirentes / Aceptantes), así como todas sus condiciones comerciales, límites de crédito, representantes legales, fiadores solidarios y datos de contacto y tesorería.

## 🏛️ 2. Arquitectura de Navegación y Estructura de la UI

La interfaz del Módulo de Registro se organiza en **2 Paneles Principales**:

```
┌────────────────────────────────────────────────────────────────────────┐
│  PANEL SUPERIOR: Buscador y Tabla Principal de Entidades               │
│  - Campo de Búsqueda Rápida: [ RUC / Razón Social ]                    │
│  - Filtro por Rol: [ TODOS | EMISOR | ACEPTANTE | AMBOS ]             │
│  - Botón Acción: [ + REGISTRAR NUEVA EMPRESA ]                         │
│  - Tabla de Resultados: RUC | Razón Social | Tipo | Tasas | Línea USD  │
└────────────────────────────────────────────────────────────────────────┘
                                   │ (Al Seleccionar o Crear)
                                   ▼
┌────────────────────────────────────────────────────────────────────────┐
│  PANEL INFERIOR / MODAL: Formulario Organizado en 7 Pestañas Temáticas  │
│  - Tab 1: Datos Generales y Ubicación Fiscal                           │
│  - Tab 2: Condiciones Comerciales y Tasas Factoring                    │
│  - Tab 3: Líneas de Crédito y Evaluación de Riesgo                     │
│  - Tab 4: Cuentas Bancarias y Tesorería                                │
│  - Tab 5: Contactos (Comercial, Cobranza y Notificaciones)              │
│  - Tab 6: Representante Legal / Depositario                            │
│  - Tab 7: Garantes / Fiadores Solidarios (hasta 4 Fiadores)            │
└────────────────────────────────────────────────────────────────────────┘
```

## 🔄 4. Acciones y Operaciones Backend en React

1. **Consulta / Listado Inicial:**
   - La UI consulta Supabase `table('EMISORES.ACEPTANTES').select('*')` mediante `factoringService.ts`.
2. **Creación / Upsert por RUC:**
   - Al guardar, la UI ejecuta un `upsert` sobre la tabla `EMISORES.ACEPTANTES` usando el `RUC` como clave de búsqueda o `id` si es una edición.
3. **Validaciones de Formularios:**
   - RUC debe constar de exactamente 11 dígitos numéricos.
   - Las tasas se expresan en números decimales o porcentajes (ej: 1.35% o 0.0135).
   - Los correos deben cumplir sintaxis estándar RFC.
