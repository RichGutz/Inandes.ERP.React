---

## ¿Qué es un QC Loop?

1. Tomar una **factura real** de `C:\Users\rguti\Inandes.ERP.React\facturas_inandes\`
2. Subirla al **Streamlit legacy** → anotar resultados
3. Subir la misma factura al **React nuevo** → anotar resultados
4. Comparar campo por campo
5. Si cuadran → ✅ producción. Si no → 🔴 bug a resolver
