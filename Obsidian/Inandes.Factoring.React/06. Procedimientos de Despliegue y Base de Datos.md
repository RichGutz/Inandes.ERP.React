## 3. Conexión con Supabase (SSL Obligatorio)

Toda conexión hacia la base de datos de PostgreSQL administrada por Supabase, ya sea desde Python (SQLAlchemy / psycopg2) o cualquier otro cliente directo de BD, **debe requerir SSL obligatoriamente**.

**Credenciales del Proyecto Supabase Unificado (`egvcinsbyropumybatdf`):**
- `SUPABASE_URL`: `https://egvcinsbyropumybatdf.supabase.co`

**Cadena de Conexión en Backend (Python):**
Asegurarse de que el String termine en `sslmode=require`:
```ini
postgresql://postgres.[PROYECTO]:[PASSWORD]@aws-0-us-west-1.pooler.supabase.com:6543/postgres?sslmode=require
```

**Conexión en Frontend (React):**
El SDK de Javascript gestiona el SSL automáticamente por debajo usando HTTPS:
```javascript
import { createClient } from '@supabase/supabase-js';
export const supabase = createClient(
  import.meta.env.VITE_SUPABASE_URL,
  import.meta.env.VITE_SUPABASE_ANON_KEY
);
```

## 4. Procedimiento Oficial de Despliegue a Producción (VPS)

El entorno de producción se aloja en el servidor VPS (`91.108.125.253`):

### 4.1 Despliegue del Frontend React
1. **Compilar el bundle:**
   ```powershell
   npm run build
   ```
2. **Subir archivos compilados (`dist/`) al servidor web Nginx (`/var/www/inandes`):**
   ```powershell
   python deploy_vps.py
   ```
3. **Guardar y sincronizar en Git (origin/main):**
   ```powershell
   git add .
   git commit -m "NOMBRE.DEL.COMMIT"
   git push origin main
   ```

### 4.2 Despliegue del Backend FastAPI en el VPS
- **Directorio en VPS:** `/opt/erp_inandes/backend`
- **Servicio Systemd:** `inandes-api.service` (Puerto 8010)
- **Comando de reinicio tras cambios en routers Python:**
  ```bash
  systemctl restart inandes-api.service
  ```
