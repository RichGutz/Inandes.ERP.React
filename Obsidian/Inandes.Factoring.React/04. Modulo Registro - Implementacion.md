# 04. Modulo Registro - Implementacion React

**Fecha de implementacion:** 16 de Julio, 2026
**Estado:** Desplegado en produccion
**URL:** https://inandes.react.geeksoft.tech → Factoring → Tab "Registro"

---

## Que hace este modulo

Es la traduccion fiel del script legacy `01_Registro.py` (Streamlit) al ecosistema React. Permite:
- **Buscar** contrapartes (Emisores/Aceptantes) existentes en la BD
- **Crear** nuevos registros con todos sus datos financieros, bancarios y legales
- **Editar** registros existentes haciendo clic en la fila de la tabla

---

## Correspondencia con el legacy (01_Registro.py)

| Streamlit | React (RegistroTab.tsx) |
|---|---|
| `BETA_TABLE = "EMISORES.ACEPTANTES"` | `const TABLE = 'EMISORES.ACEPTANTES'` |
| `vista_registro` session state ('busqueda' / 'crear' / 'editar') | Estado `vista: Vista` en React |
| `selectbox` con opciones "RAZON SOCIAL / RUC" | Tabla filtrable, clic en fila navega a editar |
| Boton `Nuevo Registro` | Boton `Nuevo Registro` abre formulario vacio |
| `st.tabs(["Identidad", "Contacto", "Financiero", "Bancario", "Garantias", "Otros"])` | Exactamente los mismos 6 tabs en el mismo orden |
| `RUC` disabled en edicion | `disabled={isEdit}` en input RUC |
| `st.form_submit_button("Guardar Registro")` | Boton "Guardar Registro" al pie del formulario |
| `guardar_registro(update=True/False)` | `supabase.update()` o `supabase.insert()` segun modo |
| `st.rerun()` + volver a busqueda | `setTimeout` + setVista('busqueda') |
| Mensaje info "solo 2 correos" en Tab Contacto | Eliminado (ahora soporta 4 correos con los nuevos campos) |
| Mensaje info "Domicilio Fiscal no disponible" en Tab Otros | Eliminado (ahora tiene Domicilio Fiscal completo) |

## Estructura del componente

```
RegistroTab (export)
├── Vista 'busqueda'
│   ├── Input de busqueda (filtro local por RUC o Razon Social)
│   ├── Boton "Nuevo Registro"
│   ├── Boton Refresh
│   └── Tabla de resultados (clic en fila → Vista 'editar')
│
└── Vista 'crear' / 'editar'  → RegistroForm
    ├── Header con boton "Volver a Busqueda"
    ├── Tabs del formulario (6 tabs)
    │   ├── Tab 0: Identidad (RUC, Tipo, Razon Social, Sector, Grupo)
    │   ├── Tab 1: Contacto (4 correos, Contacto Comercial, Contacto Cobranza)
    │   ├── Tab 2: Financiero (tasas, comisiones, lineas de credito, calificacion)
    │   ├── Tab 3: Bancario (Institucion, cuentas PEN/USD, CCIs)
    │   ├── Tab 4: Garantias (Depositario + 4 Garantes/Fiadores con domicilio)
    │   └── Tab 5: Otros (Domicilio Fiscal, Observaciones)
    ├── Mensajes de error/exito
    └── Boton "Guardar Registro"
```

## Enriquecimiento de la base de datos

Antes de este modulo, `EMISORES.ACEPTANTES` en la Supabase de React tenia **29 columnas**. Durante esta sesion se ejecuto un `ALTER TABLE` para llevarla a **73 columnas**, adoptando todos los campos de `EMISORES.ACEPTANTES.BETA` que faltaban.

Ver detalles en [[01. Entendimiento de la Base de Datos]].

## Fix de infraestructura relacionado

Durante esta sesion tambien se resolvio el error de Streamlit:
```
Error al cargar credenciales del Service Account: Service Account credentials not found
```

**Causa:** El archivo `sa_credentials.json` existia localmente pero nunca habia sido subido al VPS.

**Solucion:**
1. Se subio el archivo a `/opt/erp_inandes/sa_credentials.json` via SFTP.
2. Se actualizo `deploy_factoring_vps.py` para que en cada deploy futuro suba automaticamente `sa_credentials.json` y reinicie el servicio `erp_inandes`.

## Mejoras de UX/UI y Exportación (Sesión actual)

1. **Exportación Universal:** Se creó la utilidad `src/lib/tableExport.ts` (basada en SheetJS para Excel y HTML-print para PDF) y el componente UI `src/components/common/ExportButtons.tsx` (con íconos de Lucide y etiquetas XLSX/PDF).
2. **Integración en Registro:** Se integraron los botones de exportación a la derecha del botón "Nuevo Registro", exportando respetando los filtros de búsqueda.
3. **Landing Page y Sidebar:** 
   - Se renombró el acceso de "ERP Factoring" a **"FACTORING"**.
   - Se modificó `App.tsx` y `MasterTemplate.tsx` para que al ingresar al ERP, el estado inicial (`activeTab='home'`) muestre una vista con los logos de **Geeksoft** e **InAndes**, manteniendo todos los acordeones del sidebar colapsados por defecto.
