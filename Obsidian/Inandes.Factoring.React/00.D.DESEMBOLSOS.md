# Módulo de Desembolsos (React)

## Propósito
El módulo de Desembolsos es el cuarto paso en el flujo de Factoring. Recibe las propuestas de operaciones que fueron "Aprobadas" (estado `APROBADO` en la tabla `propuestas`), y permite a Operaciones registrar el pago, generar el voucher de transferencia y subir los sustentos a Google Drive. Una vez registrado, el estado pasa a `DESEMBOLSADA`.

## Flujo de Trabajo
1. **Carga de Datos:** El frontend llama al endpoint `GET /api/desembolsos/pendientes` que ejecuta `db.get_approved_proposals_for_disbursement()` (estado `APROBADO`).
2. **Navegación UI:** Mantiene la misma estructura de "Aprobaciones" (Navegación alfabética, Acordeones Empresa > Lote > Grupo). Permite seleccionar facturas de una misma empresa/moneda a la vez.
3. **Generación de Voucher:**
   - Para las facturas seleccionadas, se consulta `db.get_signatory_data_by_ruc()` para obtener la información bancaria del Beneficiario (Banco, Cuenta, CCI).
   - Se provee un botón para **Generar Voucher PDF** usando `generar_voucher_transferencia_pdf` y se habilita su descarga/visualización en UI.
4. **Formalización (Archivos y Fechas):**
   - El usuario ingresa la **Fecha de Desembolso real**.
   - Sube la evidencia del pago (sustento de pago). Permite **Sustento Único** (un archivo para todo el lote) o individual por factura.
5. **Selección de Drive y Ejecución:**
   - Se utiliza el componente interactivo de árbol de carpetas de Drive (ya disponible en Originación) para seleccionar la carpeta destino.
   - Al ejecutar `POST /api/desembolsos/registrar`, el backend:
     - Cambia el estado a `DESEMBOLSADA` usando `update_proposal_status`.
     - Registra la auditoría con monto y fecha real.
     - Sube el *Voucher* generado y los *Sustentos* (archivos cargados) a Google Drive usando la API.

## Endpoints Proyectados (FastAPI - `routers/desembolsos.py`)
- `GET /api/desembolsos/pendientes`: Retorna facturas en estado `APROBADO`.
- `GET /api/desembolsos/datos-bancarios/{ruc}`: Retorna datos bancarios para el Voucher.
- `POST /api/desembolsos/generar-voucher`: Recibe facturas y RUC, genera el PDF y lo retorna en base64.
- `POST /api/desembolsos/registrar`: Ejecuta actualización de DB y subida a Drive.
